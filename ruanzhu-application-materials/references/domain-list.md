
# 软件领域清单

## 主领域池（15 个，优先使用）

生成软著名称与功能规格时，从以下领域池中选取。要求：个性化、差异化、体现多领域业务功能，越独特越好（通过率高）。

| 编号 | 领域 |
|------|------|
| 1 | 企业管理信息化 |
| 2 | 移动互联网应用 |
| 3 | 人工智能与机器学习 |
| 4 | 大数据与数据分析 |
| 5 | 云计算与云原生 |
| 6 | 物联网与嵌入式 |
| 7 | 工业互联网与智能制造 |
| 8 | 金融科技 |
| 9 | 医疗健康信息化 |
| 10 | 智慧教育 |
| 11 | 游戏与数字娱乐 |
| 12 | 网络安全与密码 |
| 13 | 智慧交通与车联网 |
| 14 | 基础软件与开发工具 |
| 15 | 政务与公共服务 |

用户可回复编号（如"3"）选择对应领域，也可自行输入自定义领域名称。

> 领域可**组合**使用（如"医疗健康信息化 + 大数据与数据分析"），组合出的题目更独特、更不易与既有软著重名。

## 通用领域备选（10 个，传统清单）

当用户明确要求传统行业方向，或需要更强的业务具象度时使用：

| 编号 | 领域 | 说明 |
|------|------|------|
| 1 | 电子商务 | 线上商城、商品管理、订单处理、支付结算 |
| 2 | 在线教育 | 课程管理、在线学习、考试测评、学员管理 |
| 3 | 医疗健康 | 挂号预约、病历管理、药品管理、健康档案 |
| 4 | 企业办公 | 流程审批、任务管理、考勤管理、文档协作 |
| 5 | 社交平台 | 用户动态、即时通讯、好友管理、内容分享 |
| 6 | 金融理财 | 记账管理、理财规划、资产统计、报表分析 |
| 7 | 物流配送 | 运单管理、路线规划、包裹追踪、仓储管理 |
| 8 | 餐饮服务 | 点餐管理、桌位预订、后厨调度、会员管理 |
| 9 | 旅游出行 | 行程规划、酒店预订、景点推荐、游记分享 |
| 10 | 农业养殖 | 种养殖管理、环境监控、溯源管理、农事记录 |

## 领域关键词映射

用于「补正模式」下根据项目真实源码反推所属领域：扫描源码中的表名、路由名、模块名，与领域关键词比对后取最接近的一个。

- 企业管理信息化：用户、角色、权限、部门、审批、考勤、公告、日志
- 移动互联网应用：登录、注册、个人中心、消息推送、分享、定位
- 人工智能与机器学习：模型、训练、推理、数据集、特征、评估、预测
- 大数据与数据分析：数据源、ETL、指标、报表、看板、聚合、统计
- 云计算与云原生：容器、镜像、集群、部署、租户、配额、编排
- 物联网与嵌入式：设备、传感器、网关、采集、指令、告警、固件
- 工业互联网与智能制造：工单、产线、工艺、质检、设备、库存、BOM
- 金融科技：账户、流水、对账、风控、额度、利率、清算
- 医疗健康信息化：患者、病历、处方、挂号、医嘱、检验、随访
- 智慧教育：课程、班级、作业、考试、成绩、题库、学习记录
- 游戏与数字娱乐：角色、道具、关卡、成就、排行、对战、背包
- 网络安全与密码：加密、签名、证书、审计、检测、策略、密钥
- 智慧交通与车联网：车辆、路线、调度、定位、轨迹、违章、站点
- 基础软件与开发工具：配置、插件、模板、构建、发布、依赖、调试
- 政务与公共服务：事项、申报、审批、证照、窗口、办件、公开
