# 中国版权保护中心软件著作权命名规范

生成软著名称时须遵守以下规则：

## 基本规则

1. **名称必须以"软件"或"系统"结尾**（如"某某管理系统"、"某某软件"）
2. **名称须具备描述性**，能体现软件的用途和功能
3. **不得包含以下内容**：
   - "中国"、"中华"、"全国"、"国家"等国家字样（除非获得授权）
   - 地名简称如"京"、"沪"、"粤"等
   - 已注册的商标名称（除非是申请人自己的商标）
   - 版本号（V1.0、2.0等）
   - 夸大宣传性词汇（"第一"、"最强"、"最全"等）
   - 纯英文字母缩写或无意义组合
4. **名称长度建议**：5-15个汉字（不含"软件/系统"后缀）

## 推荐格式

```
[品牌/公司名称] + [功能/用途描述] + [软件/系统/平台]
```

## 示例

- 好的名称：
  - `智学在线教育管理软件`
  - `云商电子商务平台系统`
  - `慧医健康档案管理软件`
  - `中小企业协同办公系统`

- 不好的名称：
  - `ERP系统`（纯英文缩写）
  - `中国最强进销存系统`（包含"中国"和"最强"）
  - `进销存管理系统V2.0`（包含版本号）

## 生成策略

针对用户选择的领域，生成5个不同风格的名称候选：
- 偏功能描述型（如"在线课程学习管理系统"）
- 偏品牌型（如"智课教育教学管理软件"）
- 偏简洁型（如"云课堂软件"）
- 偏全面型（如"综合教务管理平台系统"）
- 偏行业专用型（结合领域术语）
