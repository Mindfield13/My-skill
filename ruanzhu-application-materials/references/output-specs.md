# 输出文件格式规范

## Explanation.txt 模板

```
开发的硬件环境：Intel Core i7-12700H处理器、16GB DDR4内存、512GB SSD硬盘

运行的硬件环境：Intel Core i5及以上处理器、8GB及以上内存、256GB及以上硬盘

开发该软件的操作系统：Windows 11 64位操作系统

软件开发环境/开发工具：Visual Studio Code、{具体后端IDE}、npm、Git

软件的运行平台/操作系统：Windows 10/11、Linux、macOS

软件运行支撑环境/支持软件：{运行时}、{数据库}、{Web服务器}

开发目的：实现{领域}的信息化管理和高效运营，提升业务处理效率。

面向领域/行业：{领域名称}行业

软件的主要功能：（700字左右，详细描述各功能模块，以段落形式呈现，不用列表）

软件的技术特点：前后端分离架构，RESTful API，响应式设计，{数据库}数据存储。
```

注意：
- 硬件环境描述须具体到处理器型号、内存容量、硬盘容量
- 主要功能部分需700字左右，以自然段落描述各模块
- 技术特点约60字，言简意赅

## Technical-documentation.md 规范

### 结构层次
```
一、一级模块名称（功能模块）
1.1 二级功能名称
（操作说明文字）
1.2 二级功能名称
（操作说明文字）

二、一级模块名称
2.1 二级功能名称
...
```

### 写作要求
- **拒绝AI味**：不用"综上所述"、"总而言之"、"此外值得一提的是"、"用户可通过...实现"等句式
- **模拟人工语气**：多用短句，像真人写的操作手册
- **截图标注**：凡是需要截图说明的地方，用【图X-X：XXX界面截图】标注，如：
  - 【图1-1：用户登录界面截图】
  - 【图2-3：商品添加成功提示截图】
- **内容要求**：每个功能模块写清操作步骤（打开哪个页面、点击什么按钮、输入什么内容、看到什么结果）

### 示例片段
```
一、用户管理模块
1.1 用户登录
打开系统首页，在右上角找到登录入口。输入已注册的用户名和密码，点击登录按钮。
系统验证信息后跳转到主界面，右上角会显示用户名。【图1-1：用户登录界面截图】

1.2 用户注册
没有账号的话，点击登录页下方的"立即注册"。填写用户名、密码、邮箱，点击注册即可。
注册成功后会自动跳转到登录页。【图1-2：用户注册界面截图】
```

## source-code.txt 规范

- 只包含源代码内容，不含任何配置文件（package.json、pom.xml、requirements.txt、.env等）
- 不含依赖目录（node_modules、venv、target等）
- UTF-8编码
- 文件之间直接连接，不加分隔线、文件路径、注释说明
- 代码本身不包含注释（已在代码生成步骤中去掉）
