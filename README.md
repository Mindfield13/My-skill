# hermes-skills

我的技能库（207 个），供 cc-switch 订阅安装 / 更新。

## 结构

每个技能一个顶层目录，内含 `SKILL.md` + 附属文件（references/ scripts/ assets/）。
这与 `anthropics/skills` 一致，cc-switch 可直接订阅本仓库安装。

## 安装

cc-switch → 技能 → 添加订阅源 → 填 `<你的GitHub用户名>/hermes-skills` → 安装

## 禁用名单（导入 Hermes 后需重新应用）

cc-switch 导入后所有技能默认启用。Hermes 侧恢复精简索引需执行：

```
hermes config set skills.disabled '<见 hermes-skills-清单 的禁用名单>'
```
